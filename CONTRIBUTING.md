# Contributing to Cobblit Engine

Thank you for your interest in contributing to **Cobblit Engine**! We appreciate your help in making this Minecraft Bedrock simulation and server engine even better.

Please follow these guidelines to ensure a smooth contribution process.

## Code of Conduct
* Be respectful and constructive in all discussions, issues, and pull requests.
* Write clean, maintainable, and well-documented Go code.

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/my-new-feature

```
 3. **Make your Changes** and ensure the engine compiles and runs cleanly without errors (go run main.go).
 4. **Commit your Changes** using clear and descriptive commit messages (e.g., feat: add new command, fix: resolve player movement bug).
   ```bash
   git commit -m "feat: description of your feature"
   
   ```
 5. **Push to your Fork:**
   ```bash
   git push origin feature/my-new-feature
   
   ```
 6. **Open a Pull Request** against the main branch of the official repository.
## Commit Message Guidelines
 * Use the imperative mood (e.g., "Add feature" instead of "Added feature").
 * Keep the summary concise and relevant to the modification made.
